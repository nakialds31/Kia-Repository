# Kia-Repository

## Dune: The Spice Path Protocol

`index.html` is a self-contained page that lays out a recommended order to read the Dune books and watch the films and series. Each entry has a critical-standing rating.

- **Sequence view:** a five-phase main path plus side quests (prequels, older adaptations, the documentary).
- **Rankings view:** every entry sorted by critical standing.
- Filters for Read, Watch and Essentials, plus a progress tracker saved in your browser.

### Publish on GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick the branch that holds `index.html` (for example `main`) and the `/ (root)` folder, then save.
4. The site will appear at `https://<your-username>.github.io/Kia-Repository/`.
